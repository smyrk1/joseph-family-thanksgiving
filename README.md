# Joseph Family Thanksgiving 2026

A mobile-friendly public-link RSVP and potluck signup app.

- Frontend: React + Vite
- Hosting: Netlify
- Shared database: Supabase
- Guest accounts: not required

Start with [SETUP.md](./SETUP.md). Run [supabase/schema.sql](./supabase/schema.sql) in the Supabase SQL Editor before deploying.
